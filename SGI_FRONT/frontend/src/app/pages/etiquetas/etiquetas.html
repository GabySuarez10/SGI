Precios impresos en la etiqueta

Los precios quedan impresos para verlos sin escanear (en pinturas y pinceles solo salen detal y por mayor). Si cambias un precio, vuelve a imprimir la etiqueta. Para el teléfono usa el QR; el código de barras es para un lector de caja. Con hoja carta salen varias etiquetas por hoja con guía de corte. Con rollo sale una etiqueta por página del tamaño exacto: en la ventana de impresión elige la impresora de etiquetas y la misma medida de papel. Para guardar un PDF elige "Guardar como PDF".
